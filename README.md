# BOM Cost Workbench

A browser-based, single-file BOM cost comparison workbench.

## Data privacy

- Imported BOM, finance, and cost data stays in the current browser's local storage.
- The repository contains no uploaded business reports or browser data.
- Built-in demo records are entirely fictional.

## GitHub Pages

The site is published from `index.html`. Push changes to the `main` branch to update the website.
