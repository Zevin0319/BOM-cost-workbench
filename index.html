ℹ️ 使用说明

1. 导入财务 BOM：支持 Oracle BI Publisher 导出的 HTML 格式 .xls 文件，自动解析表头、明细和成本汇总。

2. 导入 Buy Parts：支持标准 .xlsx 多 Sheet 文件，自动识别包含 "Part Number" 的表头行。

3. 物料成本库：所有导入的物料成本会自动更新到成本库，按料号去重，保留最新版本。

4. 型号对比：选择两个型号后，可查看共用物料差异和各自独有物料，按差异金额排序快速定位成本差异点。

5. 数据持久化：数据保存在浏览器 localStorage 中，刷新页面不丢失。
